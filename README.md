# Neon Sunset - Harness Maxxing theme

Dark glass, purple night, neon pink accent and orange sunset glows.

![Neon Sunset](preview.png)

- Base: Glass, dark mode only
- Fonts: Outfit, JetBrains Mono
- Custom logo: the Harness creature with sunglasses, neon on black
- Values only, no advanced CSS

## Install

Ask Harness in any session: "install the theme neon-sunset from Community",
then pick it in Settings -> Appearance -> Theme.
